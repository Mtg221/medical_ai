Across all 1,624 locked test lesions, cross-seed standard deviation correlates positively with misclassification (Pearson r = 0.296). High-agreement predictions achieve 4.2% error, while flagged predictions (> 0.12) have 38.8% error.

Sur les 1 624 lésions du jeu verrouillé, l'écart-type inter-graines corrèle fortement avec l'erreur (Pearson r = 0,296). Les prédictions à fort consensus atteignent 4,2 % d'erreur contre 38,8 % pour les cas signalés (> 0,12).
